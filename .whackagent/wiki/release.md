# Release

GitHub Releases = install channel. Flow for humans: `docs/RELEASING.md`.

- **Ship** = `scripts/release/release.sh [X.Y.Z] [--yes] [--dry-run]`, run by human on Apple silicon Mac, no Claude needed (bash + git, gh, swift, plutil, python3). `berth release` ≠ this: device give-back verb.
- **Version**: arg, else lowest open Plane module titled `X.Y.Z` (`.github/board/wa-backlog milestones`, needs `PLANE_API_KEY`). Regex rejects leading zeros. Plane read once, before any change, when key set: serves version lookup + step 10 close decision.
- **Checks before any change**: tools on PATH, `gh auth status`, macOS arm64, on `main`, clean tree (untracked included), `main` == `origin/main` after fetch, tag absent locally + on origin (`ls-remote --exit-code`, exit 2 = absent), release absent (`gh api …/releases/tags/<tag>`, only 404 = absent), no leftover draft for tag (`gh release list`). Then plan printed + `Proceed? [y/N]` (`--yes` skips, `--dry-run` exits 0 after plan, nothing changed).
- **Steps**: 1 plugin versions (`claude-plugin/.claude-plugin/plugin.json` `version`, `.claude-plugin/marketplace.json` `plugins[0].version`) ≠ X.Y.Z → branch `release/set-X.Y.Z`, sed version lines, PR, `gh pr merge --squash --delete-branch` at once (main unprotected), pull. 2 `swift test`. 3 `package.sh` into temp dir. 4 tag `vX.Y.Z` + push. 5 `gh release create --draft --verify-tag --generate-notes`. 6 upload both assets. 7 both asset names on draft, else stop. 8 `gh release edit --draft=false --latest` → `releases/latest` moves. 9 bump `X.(Y+1).0` via `release/bump-…` PR, merged at once. 10 `wa-backlog close-milestone X.Y.Z` (module → `completed`); kept open, reason in plan + step line, when `PLANE_API_KEY` unset, Plane unreadable (arg given) or no open module `X.Y.Z`: release still ships, exit 0.
- Tests + build run before tag push → failure there leaves nothing public.
- **Failure**: ERR trap (`set -E`, subshells exit quiet) prints failed step + cleanup for what this run made: half-done version PR (switch main, delete branches, close PR), tag + draft delete commands. After publish → "release is live, do not delete it", bump PR by hand. After bump → live + bumped, close module by hand (`close-milestone`). Script never deletes tag or release itself. No resume.
- Next Plane module never created: humans own modules.
- **CI**: `.github/workflows/release.yml` = PR check only (PR touching workflow, `scripts/release/**`, `Package.swift`, `Version.swift`): `swift test` + `package.sh 0.0.0` + artifact. No tag trigger, no publish job: local build = only publisher.
- **Version stamp**: `BerthCore/Version.swift` `BerthVersion.current` = `"dev"` in repo. `package.sh` stamps version (sed on `"dev"` literal), restores file on exit → tree stays clean. `berth --version` reads it. Plugin version ≠ CLI version in source; aligned per release by step 1.
- **Assets** (stable names → `releases/latest/download/<asset>` permalink, README, root `install.sh` (`curl … | bash`, SHA-256 checked, rename install → #26) + auto update rely on it): `berth-macos-arm64.tar.gz` (`berth` + `berth-bar` at root), `berth-macos-arm64.tar.gz.sha256` (`shasum -a 256`, relative name → `shasum -c` works).
- arm64 only. No signing/notarization: curl download has no quarantine xattr, ad-hoc linker signature runs.
- Actions pinned to commit SHAs, checkout `persist-credentials: false`.
- Consumer: [[update]] (feed, asset names, version compare).
